自我介绍

关于我——一个把"想法"落地成"能跑的代码"的数据科学与大数据技术专业学生。

关于我

我是计算与智能技术学院数据科学与大数据技术专业的学生。对「数据 × 智能体」有着持续的热情：既关心数据本身——如何采集、清洗、建模并让数字说话，也关心如何把一段流程交给智能体自主完成。

在课程与实践中，我独立完成了多个从 0 到 1 的项目：从 HarmonyOS 应用开发、开源许可证合规智能体，到门店补货数字化协同系统，以及面向真实场景的 AI 投标平台原型。每一个项目都坚持「可运行、可复现、可交付」——代码在 GitHub 开源，Demo 可在浏览器直接打开体验。

我习惯用工程化的方式思考问题：先定义清楚口径与边界，再动手实现；关注规则引擎、工具调用（Function Calling）、数据契约与可追溯性。我相信，一个优秀的方案不是「预测得最准」，而是「最经得起复核」。

智能体实验项目

把判断逻辑交给智能体自主完成——工具调用驱动的合规检查智能体。

智
Python · Agent

LicenseLens · 开源许可证合规检查智能体

输入一个项目目录，智能体自主决定「先看什么、再查什么」，最终输出合规报告。自实现 6 个工具（扫描 / 识别许可证 / 解析依赖 / 查询许可证 / 规则表判定 / 落盘报告），支持 plan（无 Key 固定流程）与 live（Function Calling 自主决策）双模式，用真实规则表判定 GPL 等冲突。
